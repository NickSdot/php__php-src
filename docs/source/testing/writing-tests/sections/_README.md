# Section Notes

## Section Table Rows

This file records the metadata rows available to section tables. It is excluded
from rendering.

Use rows in this order and omit rows that do not apply:

1. `Mandatory`
2. `Position`
3. `Default`
4. `Content`
5. `Case`
6. `Lines`
7. `Separator`
8. `Requires`
9. `Alternatives`

`Alternatives` lists mutually exclusive substitutes. `Position` describes the
preferred source order in the test file.
